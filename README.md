# Achievement Companion

Помощник для прохождения Steam-игр на 100%: список достижений с оценкой времени, автоучёт полученного,
ручные отметки "сделано, но не засчиталось", план прохождения, оверлей поверх игры и (по желанию)
запись отмеченного в Steam через встроенный SAM.API.

ТЗ и архитектура: документ "Achievement Companion - ТЗ и архитектура".

## Сборка и запуск

Нужно: Windows 10/11, .NET 10 SDK (или Visual Studio 2026 / 2022 17.14+ с .NET 10), Steam.

```
dotnet build AchievementCompanion.sln -c Release
src\AC.App\bin\Release\net10.0-windows\AchievementCompanion.exe
```

Собирать нужно решение целиком: помощник `AC.SteamBridge` (x86, self-contained) собирается отдельно
и копируется в подпапку `bridge\` рядом с приложением.

Тесты (обычное консольное приложение, без пакетов):

```
dotnet run --project tests\AC.Core.Tests
```

## Первый запуск

1. Настройки: вставить Web API ключ (кнопка "Получить ключ" открывает steamcommunity.com/dev/apikey),
   SteamID64 подставляется сам из локального Steam.
2. Для статуса через Web API в приватности Steam должны быть открыты "Сведения об играх".
   Если профиль скрыт - в настройках выбрать источник статуса "Steam-клиент".
3. "Обновить библиотеку из Steam", выбрать игру.
4. Чтобы появились оценки времени: задать "Время до 100%" (часы) или нажать "Взять с completionist.me".

## Что где

| Проект | Что внутри |
| --- | --- |
| `src/AC.Core` | модели, сведение статусов, классификатор типов, оценка времени, планировщик, экспорт, разбор файлов Steam |
| `src/AC.Infrastructure` | хранилище JSON, Steam Web API, реестр и файлы Steam, запуск помощника, сценарии (`GameService`) |
| `src/AC.SteamBridge` | помощник x86: `read`, `unlock`, `lock` через Steam-клиент; внутри SAM.API (zlib) |
| `src/AC.App` | WPF: главное окно, план, настройки, оверлей, горячие клавиши |
| `tests/AC.Core.Tests` | 18 тестов логики и хранилища |

Данные: `%LocalAppData%\AchievementCompanion\` (по файлу на игру в `games\`, `settings.json`,
журнал записей в Steam `unlock_log.jsonl`). API-ключ хранится зашифрованным (DPAPI).

## Горячие клавиши

- `Ctrl+Shift+A` - показать / скрыть оверлей.
- `Ctrl+Shift+S` - режим кликов в оверлее (можно отмечать и перетаскивать). Без него клики проходят в игру.

Оверлей виден в оконном и borderless режиме игры, в эксклюзивном полноэкранном - нет.

## Время в игре

- "Реально наиграно, ч" - своё значение вместо времени Steam (например, много AFK).
- "Не считать из Steam, ч" - часы, которые не идут в прогресс: до того, как в игру добавили достижения, или AFK.

## Автоотметка

Статус обновляется сам, без ручных отметок: когда Steam переписывает файл статистики игры
(`appcache\stats\UserGameStats_*_<appid>.bin`) и по таймеру, пока игра запущена.
Полученное достижение становится "открыто", ручная отметка на нём закрывается сама,
в оверлее появляется строка "Открыто: ...".

## Запись в Steam (SAM)

По умолчанию выключена. Режимы в настройках: "только отмечать", "отметка + сразу в Steam",
"копить и отправлять по кнопке". Время открытия в Steam = время записи. Защищённые достижения
(ставит только сервер игры) записать нельзя. Снять записанное: правый клик по строке.

## Что проверить на живом Steam (здесь не проверялось)

Код собран и протестирован только частично: `AC.App` (WPF) собирается только на Windows,
в среде разработки его скомпилировать было нельзя. Проверить в первую очередь:

1. Сборку `AC.App` и копирование `bridge\` в выходную папку.
2. `bridge\AC.SteamBridge.exe read <appid>` в консоли при запущенном Steam - должен вернуть JSON.
3. Чтение через Steam-клиент при запущенной игре (два процесса с одним AppID).
4. Срабатывает ли слежение за файлом статистики при получении достижения в игре.
5. Разбор страницы completionist.me (вёрстка может отличаться от ожидаемой).
