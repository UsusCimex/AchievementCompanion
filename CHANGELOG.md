# Изменения

## 0.4.0
- Своя статистика по игрокам: авторы обзоров Steam, проценты и время к каждому достижению (для игр без глобальной статистики Steam).
- "Как получить": поиск гайдов Steam, обсуждений, YouTube и Google по достижению.
- Шапка игры с артом из библиотеки Steam, цвет редкости, полоса статуса у карточки.

## 0.3.0
- Новый интерфейс на теме Fluent (светлая/тёмная по системе): библиотека с обложками, карточки, панель достижения, вкладка "Время".
- Новый оверлей, иконка приложения.
- GitHub Actions: CI и релиз по тегу. Лицензия MIT.

## 0.2.0
- Кнопка "В Steam" как в SAM, массовая запись выделенных.
- Глобальные проценты запрашиваются после сбора списка (раньше терялись без ключа).
- Время до 100% выводится из своего прогресса, если не задано.
- Описания скрытых видны в оверлее.

## 0.1.0
- Первая версия: список, статусы, ручные отметки, планировщик, оверлей, помощник SAM.API, экспорт, своё время в игре, автообновление статуса.
